# oh my code

> A coding agent CLI that works on your code when you say “oh my god”.

🚧 **Work in Progress**  
This project is experimental. APIs, behaviors, and architecture may change frequently.

---

## What is this?

**oh my code** is a coding agent CLI designed to explore, understand, modify, and evolve a codebase autonomously.

It is inspired by tools like Claude Code, but focuses on:
- agent loops
- long-running workflows
- working *on* your code, not just generating snippets

---

## Why does this exist?

Sometimes your codebase reaches a point where you can only say:

> *oh my god…*

That’s when **oh my code** steps in.

---

## Status

- Early exploration
- No stable interface yet
- Expect breaking changes
